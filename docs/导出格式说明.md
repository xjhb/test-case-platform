# 测管平台 导出格式说明文档

本文档说明测管平台所有 Excel 导出/导入功能的文件格式。

---

## 一、测试用例导出 Excel

**入口**:测试用例页 →「导出用例」按钮(需先选择项目)
**接口**:`GET /api/testcases/export?project_id={id}`
**文件名**:`testcases.xlsx`

### Sheet:测试用例

| 列 | 字段 | 说明 |
|----|------|------|
| A | ID | 用例编号 |
| B | 模块 | 功能模块,如"登录"、"下单" |
| C | 用例标题 | 测试点一句话描述 |
| D | 优先级 | P0/P1/P2/P3 |
| E | 前置条件 | 执行前需要满足的条件 |
| F | 测试步骤 | 详细操作步骤 |
| G | 预期结果 | 期望发生的现象 |
| H | 当前状态 | 未执行/通过/失败/阻塞(最新一次执行结果) |
| I | 创建时间 | 格式 YYYY-MM-DD HH:MM |

> 首行蓝底白字表头,首行冻结,按 ID 升序排列。

## 二、测试报告导出 Excel

**入口**:测试计划页 → 每行「导出报告」按钮
**接口**:`GET /api/reports/plan/{plan_id}/export`
**文件名**:`test_report_{版本}_{时间戳}.xlsx`

### Sheet 1:测试概览

顶部标题行(深蓝底白字),下方为基本信息:

| 项目 | 值 |
|------|----|
| 项目名称 | xxx |
| 计划版本 | v1.0 |
| 当前阶段 | SIT / UAT / PRE |
| 计划状态 | 进行中 / 已完成 |
| 用例总数 | N |
| 生成时间 | YYYY-MM-DD HH:MM:SS |

下方为**阶段执行统计表**:

| 阶段 | 用例总数 | 通过 | 失败 | 阻塞 | 未执行 | 通过率 |
|------|---------|------|------|------|--------|--------|
| SIT  | N       | x    | x    | x    | x      | xx.x%  |
| UAT  | N       | x    | x    | x    | x      | xx.x%  |
| PRE  | N       | x    | x    | x    | x      | xx.x%  |

### Sheet 2:用例明细

每条用例一行,展示三个阶段的**完整执行信息**:

| 列 | 字段 | 说明 |
|----|------|------|
| A | ID | 用例编号 |
| B | 模块 | |
| C | 用例标题 | |
| D | 优先级 | |
| E | 前置条件 | |
| F | 测试步骤 | |
| G | 预期结果 | |
| H | SIT结果 | 通过(绿)/失败(红)/阻塞(黄)/未执行(灰) |
| I | SIT执行人 | |
| J | SIT执行时间 | YYYY-MM-DD HH:MM |
| K | SIT备注 | |
| L | UAT结果 | 同上颜色 |
| M | UAT执行人 | |
| N | UAT执行时间 | |
| O | UAT备注 | |
| P | PRE结果 | |
| Q | PRE执行人 | |
| R | PRE执行时间 | |
| S | PRE备注 | |
| T | 当前阶段状态 | 计划当前阶段的状态(带颜色) |

> D 列冻结,结果列按状态着色:通过=绿,失败=红,阻塞=黄,未执行=灰

### Sheet 3:失败阻塞汇总

汇总所有阶段中结果为"失败"或"阻塞"的记录,方便快速定位问题:

| 列 | 字段 |
|----|------|
| A | 阶段 |
| B | ID |
| C | 模块 |
| D | 用例标题 |
| E | 结果(带颜色) |
| F | 执行人 |
| G | 执行时间 |
| H | 备注 |

## 三、测试用例导入

**入口**:测试用例页 →「导入用例」按钮
**接口**:`POST /api/imports?project_id={id}`
**支持格式**:`.xlsx`、`.csv`
**模板下载**:`GET /api/imports/template`(下载 testcase_template.xlsx)

### 文件格式(表头必须与模板一致)

| 模块 | 用例标题 | 前置条件 | 测试步骤 | 预期结果 | 优先级 |
|------|---------|---------|---------|---------|--------|
| 登录 | 正确登录成功 | 已打开页面 | 1.输入账号 2.输入密码 3.点击登录 | 跳转首页 | P1 |
| 下单 | 下单成功 | 已登录 | 1.选商品 2.结算 | 生成订单 | P0 |

### 导入规则

- **用例标题**:必填,为空则跳过该行
- **优先级**:可选 P0/P1/P2/P3,不填或无效默认 P1
- **其他列**:可留空
- CSV 编码:UTF-8(支持带 BOM)
- 返回:`{created: 成功数, failed: 失败数, errors: [失败原因]}`

## 四、阶段状态颜色对照

| 状态 | 颜色 | 色值 |
|------|------|------|
| 通过 | 绿 | C6EFCE |
| 失败 | 红 | FFC7CE |
| 阻塞 | 黄 | FFEB9C |
| 未执行 | 灰 | F2F2F2 |

## 五、权限说明

| 操作 | 管理员(admin) | 普通成员(member) |
|------|--------------|-----------------|
| 导出用例 | 所有项目 | 仅分配的项目 |
| 导出报告 | 所有项目 | 仅分配的项目 |
| 导入用例 | 所有项目 | 仅分配的项目 |
| 全阶段总览 | 可用 | 不可用(退回单阶段模式) |
