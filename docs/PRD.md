## 1. 产品概述

### 1.1 产品定位
面向金融/银行行业内部团队的**测试用例全生命周期管理平台**，覆盖从需求分析、用例设计、评审、执行到缺陷跟踪的完整测试流程。

### 1.2 目标用户
- **测试经理**：创建测试计划、分配任务、查看统计报告
- **测试工程师**：编写用例、执行测试、提交缺陷
- **项目经理**：查看项目进度、测试覆盖率
- **系统管理员**：用户管理、权限配置、系统设置

### 1.3 核心价值
- 统一测试资产管理，避免 Excel 分散管理
- 支持 SIT/UAT/PRE 多阶段灵活推进
- 缺陷与用例关联，追溯测试覆盖
- 自动化集成，支持 CI/CD 流水线

## 2. 功能需求

### 2.1 用户认证与权限

#### 2.1.1 登录/登出
- 用户名密码登录，JWT Token 认证
- 登录超时自动登出（可配置，默认 30 分钟）
- 密码有效期管理（可配置，默认 30 天）
- 密码到期前提醒（可配置，默认 10 天）
- 管理员重置密码后强制首次登录修改

#### 2.1.2 角色权限
| 角色 | 权限范围 |
|------|---------|
| admin | 全部功能 + 用户管理 + 系统配置 |
| member | 项目内用例/缺陷/执行操作 |

#### 2.1.3 个人信息
- 修改密码（原密码验证）
- 编辑个人资料（显示名称、邮箱、手机号）
- 外包人员信息（员工编号、供应商、系统名称等）

---

### 2.2 项目管理

#### 2.2.1 项目信息
- 项目名称、编号、描述
- 项目等级、类型
- 测试经理、技术经理、SA
- 是否重点项目、启动状态
- 星标关注功能

#### 2.2.2 项目权限
- 成员只能看到分配给自己的项目
- 项目内角色动态定义（管理员可创建/编辑角色）
- 默认系统角色：项目经理、测试负责人、测试员、只读用户

---

### 2.3 测试用例管理

#### 2.3.1 用例属性
| 字段 | 说明 |
|------|------|
| 标题 | 用例名称 |
| 模块 | 所属功能模块 |
| 前置条件 | 执行前提 |
| 步骤 | 操作步骤 |
| 预期结果 | 期望输出 |
| 优先级 | P0/P1/P2/P3 |
| 状态 | 未执行/通过/失败/阻塞 |
| 评审状态 | 草稿/评审中/已批准/已驳回 |

#### 2.3.2 用例组织
- **文件夹树**：支持多级目录组织用例
- **标签系统**：自定义标签分类
- **自定义字段**：项目级扩展字段

#### 2.3.3 用例评审
- 提交评审 → 评审人审批/驳回
- 评审意见记录
- 评审状态流转

#### 2.3.4 版本历史
- 用例修改自动保存版本
- 版本对比查看
- 版本回滚功能

---

### 2.4 测试计划与执行

#### 2.4.1 测试计划
- 关联项目、版本号
- 三阶段时间规划（SIT/UAT/PRE）
- 阶段默认天数可配置

#### 2.4.2 阶段推进（灵活模式）
- **顺序推进**：SIT → UAT → PRE
- **跳跃推进**：可直接从 SIT 跳到 UAT 或 PRE
- **回退限制**：只能向前推进，不能回退
- 不再强制要求 100% 通过才能推进

#### 2.4.3 测试执行
- 单条用例执行记录（通过/失败/阻塞）
- 执行备注、截图上传
- 执行历史记录

#### 2.4.4 测试轮次
- 计划下创建多个执行轮次
- 轮次独立统计
- 轮次完成标记

#### 2.4.5 批量执行
- 选择多条用例批量标记状态
- 批量分配执行人员

## 4. 非功能需求

### 4.1 性能
- 页面加载时间 < 2 秒
- API 响应时间 < 500ms（95% 请求）
- 支持 100+ 并发用户

### 4.2 安全
- 密码加密存储（bcrypt）
- JWT Token 认证
- 操作日志审计
- 密码有效期管理

### 4.3 可用性
- 支持 Chrome、Edge 等主流浏览器
- 响应式布局（适配 1920x1080 及以上）
- 中文界面

### 4.4 可扩展性
- 模块化架构，便于功能扩展
- Nacos 配置中心支持（可选）
- 自定义字段支持

## 7. 附录

### 7.1 角色定义
| 角色代码 | 角色名称 | 说明 |
|---------|---------|------|
| manager | 项目经理 | 项目管理员，拥有项目的全部管理权限 |
| test_lead | 测试负责人 | 测试经理/测试组长，负责测试计划和用例管理 |
| tester | 测试员 | 测试执行人员，负责执行测试用例和提交缺陷 |
| viewer | 只读用户 | 仅可查看项目信息，无编辑权限 |

### 7.2 用例优先级
| 优先级 | 说明 |
|--------|------|
| P0 | 核心功能，必须测试 |
| P1 | 重要功能，优先测试 |
| P2 | 一般功能，正常测试 |
| P3 | 边缘场景，可选测试 |

### 7.3 缺陷严重程度
| 严重程度 | 说明 |
|---------|------|
| 致命 | 系统崩溃、数据丢失 |
| 严重 | 主要功能不可用 |
| 一般 | 次要功能异常 |
| 提示 | 界面/体验问题 |
